# Slide content, not image-model prompts

The OpenRouter slide-image generator was removed from this fork. Do not send slide text, citations, or unpublished figures to a third-party image API to render the deck.

Write the talk in the Beamer templates under `assets/` or in PowerPoint (`assets/powerpoint_design_guide.md`). Keep quantitative results in editable text or in figures produced by matplotlib, Graphviz, or Mermaid. A prompt is not a source.
