# Figures for posters

Draw plots from the analysis that produced the numbers (matplotlib or the project's plotting script) and precise diagrams in TikZ, Graphviz, or Mermaid.

The upstream `generate_schematic.py` helper was removed. It read parent `.env` files for an OpenRouter key and sent the prompt to a paid image API. Do not replace it by pasting unpublished results into a third-party image service unless the user explicitly asks.

Keep titles, citations, numerical values, and QR codes editable in LaTeX. An image is not a source for a sample size or an effect estimate.
